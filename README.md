# Medicost Insight – Insurance Cost Prediction System

Medicost Insight is a Machine Learning-based insurance cost prediction system developed to estimate insurance charges using demographic, lifestyle, and personal attributes.

The project uses **Random Forest Regression** to learn patterns from an insurance dataset and generate estimated insurance costs based on user-provided inputs.

> **Note:** This project is developed for educational and machine learning practice purposes. The predictions should not be considered actual insurance quotes or professional financial/medical advice.

---

## 📌 Project Overview

Insurance costs can vary depending on several factors such as age, BMI, smoking status, number of dependents, and other personal characteristics.

Medicost Insight applies Machine Learning techniques to analyze these factors and predict an estimated insurance charge.
